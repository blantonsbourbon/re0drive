# 验证记录

日期：2026-10-09。Rust 1.85.1，Linux x86_64，Chrome headless。

## 自动测试

`cargo test --locked`：16 项通过（7 项原客户端协议向量/解析测试，9 项本地 HTTP 流程与持久化测试）。

- 原客户端 HMAC 与授权链接的已知签名，查询排序与空值。
- RE0 签名 HTTP 搜索、详情、解锁、用户状态和普通签到。
- 115 两页共 102 个文件/目录的查询与 Cookie form 接收。
- 重新查询的价格超限、未知、负数时没有任何解锁/接收请求。
- 响应中断或缺少成功标识保留待核对；不自动重试外部写入。
- 账号/订阅变化阻止原排队操作；成功去重，已跳过资源允许再排队。
- 超过界面 200 条展示上限的任务也能重启恢复。
- 数据库不含已写入凭据的明文，master.key 权限为 0600；一次性导入文件被加密并删除。
- 管理员初始化、会话、CSRF、凭据只写、退出使会话失效。
- `success:true` 与 `REAUTH_REQUIRED` 符号码兼容。

## 浏览器

独立演示实例执行以下流程，JavaScript 运行错误数为 0：

创建管理员 → 搜索示例资源 → 筛选画质 → 手动转存 → 检查演示不计入真实成功 → 创建/扫描/编辑/停用订阅 → 保存设置 → 验证 Cookie 不回显 → 查询演示账号状态 → 手机视口 → 退出重登。

视口：1440×1000 与 390×844；手机页面没有横向溢出。示例截图位于工作空间 `artifacts/`。

## Release 与简单性能采样

Release 编译成功，Linux x86_64 单个可执行文件约 8.6 MiB，内嵌网页资源。所需的最高 glibc 符号版本为 2.34。

仅对本机小型演示数据库的登录后工作台接口采样：200 次请求、4 个并发、Python HTTP 客户端；约 2748 请求/秒，中位 1.23 ms、P95 1.79 ms。这是开发机局域回环采样，**不是外部 RE0 / 115 的耗时，也不是不同语言/框架的对比测试**。原始采样信息见工作空间 `artifacts/performance.json`。

## 默认网关验证

从本地成品导入连接密钥后，独立 Rust 客户端发送未授权安装标识的只读 `/api/token/status` 请求，成功返回 `authorized:false`。没有发送真实账号的签到、解锁或 115 转存请求。

真实 OAuth 授权、资源响应字段、积分计费和 115 接收仍需要连接账号后联调。当前环境没有 Docker CLI / daemon，提供的 Dockerfile 与 Compose 尚未构建运行验证。
